## New Mexico Backyard Refuge Web Map
Web map and code by GeoAIR Lab from University of New Mexico for the New Mexico Backyard Refuge Program (NM BYR). The NM BYR is part of Ciudad Soil & Water Conservation District, and Friends of Valle de Oro. This web map is supported by the R.H. Mallory Center for Community Geography at the University of New Mexico.  Learn more about the NM BYR on the full website. https://friendsofvalledeoro.org/abq-backyard-refuge/
